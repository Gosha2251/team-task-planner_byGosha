# Virtuāls uzdevumu plānotājs komandai

---

## Projekta apraksts

Virtuāls uzdevumu plānotājs komandai ir tīmekļa lietotne, kas paredzēta komandas darba organizēšanai. Sistēma ļauj pārvaldīt komandas, veidot uzdevumus, piešķirt tos lietotājiem, sekot izpildes statusam un pievienot komentārus.

---

## Izmantotās tehnoloģijas

- Python
- Flask
- MariaDB
- HTML
- CSS
- JavaScript
- GitHub
